# rawfawv.github.io 프로젝트

## 개요
GitHub Pages로 호스팅되는 개인 포트폴리오 사이트. 브랜드명은 "CACAZOO", 작가명은 Jiwoon Chung.

## 기술 스택
- 순수 HTML, CSS, JavaScript (프레임워크/빌드 도구 없음)
- 별도의 패키지 매니저나 번들러 미사용
- 정적 파일 직접 서빙

## 프로젝트 구조
```
/
├── index.html          # 메인 포트폴리오 페이지
├── main.js             # 갤러리 인터랙션 (드래그, 뷰 전환)
├── style.css           # 전체 스타일 (CSS Variables 사용)
├── assets/             # 포트폴리오 이미지
├── fish-game/          # 서브 프로젝트: 어항 물고기 게임
│   └── index.html      # 단일 파일 게임 (HTML+CSS+JS 인라인)
├── spider-game/        # 서브 프로젝트: 거미줄 인터랙션 게임
│   └── index.html      # Canvas 기반 거미줄 배경 (마우스 왜곡 + 클릭 파동)
└── brush-game/         # 서브 프로젝트: 폰트 애니메이션 도구
    └── index.html      # 폰트 끝 부분 스르륵 나타나는 모션 생성기
```

## 디자인 시스템
- 컬러: `--bg: #F5F7F8`, `--ink: #121212`, `--accent-orange: #e06d48`
- 폰트: Syne(디스플레이), Inter(본문), DM Mono(코드/레이블)
- 스타일: NYT Magazine 에디토리얼 + Swiss 미니멀리즘

## 코딩 컨벤션
- 한국어 주석 사용
- 외부 라이브러리 최소화 (vanilla JS 선호)
- CSS는 BEM 대신 직관적인 클래스명 사용
- 접근성 고려 (aria-label, semantic HTML)
- 반응형 디자인 (모바일 768px 기준)

## 주요 기능
### 메인 페이지
- 두 가지 뷰 모드: 한줄보기(shelf), 모아보기(grid)
- 드래그 기반 가로 스크롤 + 모멘텀 효과
- 마우스/터치/휠 모두 지원

### fish-game
- Canvas 기반 인터랙티브 게임
- 물고기 키우기 → 질문 → 엔딩 분기
- 단일 HTML 파일에 모든 코드 포함

### spider-game
- Canvas 기반 거미줄 인터랙션 게임
- 방사형 거미줄 패턴 (동심원 + 방사선)
- 마우스에 거미가 따라다님 + 랜덤 말풍선 (킹받는 멘트)
- 벌레 13종류 자동 생성 (랜덤 위치, 크기별 클릭 수 차등)
- 거미 근접 시 벌레 떨림 + 비명 말풍선 (각 벌레 이름별로 다름)
- 벌레 클릭 → 하얗게 변하며 식량창고로 이동 + 칭찬 멘트
- "도망쳐" 음성 인식으로 벌레 날려보내기 (3번 사용 시 거미 굶어 죽음 엔딩)
- **난이도 선택 기능:**
  - 쉬움: 7개 벌레, 분홍색 배경(#ffafeb→#ff7794), 소박한 엔딩
  - 어려움: 13개 벌레, 초록색 배경(#98d62c→#456114), 폭죽/하트눈 엔딩
- 수집 완료 시 엔딩 화면 (눈 내리기, 거미, 난이도별 다른 메시지)
- 단일 HTML 파일에 모든 코드 포함

### brush-game
- 폰트 애니메이션 도구 (특정 영역이 스르륵 나타나는 모션)
- **UI 테마**: 라이트 모드 (화이트 배경)
- **마스크 최대 2개까지 지원** (첫 번째: 초록색, 두 번째: 노란색)
- **마스크별 개별 설정**: 각 마스크마다 방향(→↓←↑), 속도, 딜레이 개별 조절 가능
- **마스크 타입 선택**: 네모(rect), 동그라미(circle), 다각형(polygon) 중 선택
  - 네모/동그라미: 드래그로 그리기
  - 다각형: 클릭으로 점 찍기 → 더블클릭 또는 첫 점 클릭으로 완성
- 마스크 영역 미리보기: 글씨가 20% 투명도로 살짝 비침
- 최대 3글자까지 지원
- 조절 가능: 폰트 크기, 자간, 색상
- 애니메이션: ease-in-out 타이밍 (cubic-bezier)
- **배경색 선택**: 화이트(#ffffff) / 그린스크린(#03ff00) 중 선택 가능
- **내보내기 옵션**:
  - MP4: WebCodecs + mp4-muxer로 브라우저에서 직접 생성 (Chrome 94+, 선택한 배경색 적용)
  - WebM 폴백: WebCodecs 미지원 브라우저용 (MediaRecorder)
  - PNG 시퀀스: 30fps 프레임별 PNG를 ZIP으로 묶어서 다운로드 (선택한 배경색 적용)
- 외부 라이브러리: JSZip (CDN), mp4-muxer (CDN)
- 고정 폰트: BAEMINWORK.otf
- 단일 HTML 파일에 모든 코드 포함
