# 레퍼런스 선반 · 코드 작업

이 폴더에 올린 HTML 작업은 [레퍼런스 선반](https://rawfawv.github.io/refs/)에 카드로 올라가요.
`https://rawfawv.github.io/refs/entries/파일이름.html` 또는 `.../entries/폴더이름/` 주소로 열려요.

## 올리는 법

1. 선반에서 **+ 코드 올리기** → **GitHub에 파일 올리기**
2. 이 폴더 화면에 HTML 파일 하나, 또는 `index.html`이 든 폴더를 끌어놓고 **Commit changes**
   (이미지·JS·CSS는 같은 폴더에 함께)
3. 선반 팝업으로 돌아와 **목록 새로 불러오기** → 올린 파일을 고르고 이름·분류·메모를 쓴 뒤 **GitHub에서 등록하기** → **Create**

등록하면 링크 카드와 똑같이 카드의 **수정**(이름·분류·메모), **썸네일 바꾸기**(등록글 댓글에 스크린샷)를 쓸 수 있어요.
카드의 **삭제**는 이 폴더의 파일을 지우는 화면으로 가요. 파일을 지우면 선반에서도 빠져요.

정보를 등록하지 않아도 카드는 보여요. 그때는 HTML `<title>`이 이름이 되고, 카드에 **정보 등록** 버튼이 생겨요.
