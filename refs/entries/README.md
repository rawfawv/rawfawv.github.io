# 레퍼런스 선반 · 코드 작업

이 폴더에 올린 HTML 작업은 [레퍼런스 선반](https://rawfawv.github.io/refs/)에 카드로 올라가요.

## 올리는 법

1. 선반에서 **+ 코드 올리기** (이 업로드 화면이 열려요)
2. HTML 파일 하나, 또는 `index.html`이 든 폴더를 끌어놓기 (이미지·JS·CSS는 같은 폴더에)
3. 아래 **Commit changes** 칸에
   - 제목 칸: `작업 이름 #분류` (예: `옥외 LED 3D 프리뷰 #목업`)
   - 설명 칸: 메모
4. **Commit changes** → 1분쯤 뒤 선반에 카드가 생겨요

제목 칸을 비우면(기본값 *Add files via upload*) HTML `<title>`이나 파일 이름이 카드 이름이 돼요.
올린 뒤 이름·분류·메모를 바꾸려면 카드의 **정보 등록**을 쓰면 돼요.
